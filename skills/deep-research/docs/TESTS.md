## 1. 定位与运行方式

- **前置条件**：agent 环境已加载 deep-research skill，且具备某种 web 搜索/抓取能力。源码场景（V-18~V-23、V-40）另需 git 与公开仓库。目录场景（V-24~V-26）需可写工作区，V-26 另需不可写路径。V-11 需无搜索工具环境；V-23 需无 web 有 git；V-29/V-39 需分别在有、无结构化提问工具的宿主验证；V-30 需声明自主执行的宿主或模拟；V-33/V-50 需 uv 可用，V-34 需无 uv 或模拟渲染失败；V-43 需有子代理工具的宿主，V-44 需无子代理工具或模拟派生失败。
- **执行方式**：按场景原文（`▶` 行）发起对话，对照 `=` 断言逐条核对。多轮按 `→` 继续。
- **判定规则**：单场景全部 `=` 通过为"通过"；任一失败为"偏离"记录编号与实际行为；"≤/≥"按字面验收；"包含"指语义包含；环境相关场景（*）缺失环境时跳过不算缺陷。
- **间隔纪律**：真实搜索按本 skill 内联纪律（间隔 ≥2s、退避重试一次、同 URL 不重抓）。

### V-2 歧义术语触发预检索（不变）


= 触发预调研校准（识别"苹果"多义：公司 / 水果品类 / 其他）
= 预检索（搜索+抓取合计）≤3 次，且查询词带领域限定（判向式，非收集式）
= 输出 2~4 个候选方向，每项 ≤2 行；优先用结构化提问工具勾选，无工具时为文本可勾选列表
