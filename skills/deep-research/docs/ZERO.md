# deep-research · 项目灵感文档

> **一句话定位**：一个“先校准问题，再消耗调研资源”的调研 Skill——把理解成本前置，把搜索资源花在确认过的问题上，最终产出**调研报告 + 素材登记簿**双文档。

---

## 1. 背景与要解决的问题

- 用户提出调研需求时，往往**对自己要调研的东西并不清晰**，直接开跑会浪费调研资源、产出偏离预期的报告。
- 反过来，**AI 也未必真正理解了用户的问题**（术语歧义、领域冷门、表述模糊），仅凭对话追问可能越问越偏。
- 现有调研类工具普遍把“理解校准”这一步后置或省略，导致结果看似完整、实则答非所问。

## 2. 核心理念

**先校准问题，再消耗调研资源。**

- 理解上的偏差应在调研开始前消除，而不是在报告交付后返工。
- 预调研的目的不是收集资料，而是**校准理解**。

## 3. 总体流程（灵感级）

```
模糊提问 → 少量预检索校准理解 → 选项式追问收敛主题
→ 推荐调研强度（用户可调）→ 分层多语言调研（边查边写入素材登记簿）
→ 交付：分级报告 + 素材登记簿 → 基于登记簿的追问与深挖
```

## 4. 三个关键机制

### 4.1 预调研校准（本 Skill 的核心亮点）

- **定位**：查 1~3 条资料的目的仅是判断“用户到底在问什么”，不是开始调研。
- **触发条件**（满足其一才查，避免简单问题被拖慢）：术语有歧义（如“苹果”）、领域冷门、用户表述模糊。
- **输出形式**：只提炼成“我理解的 2~4 个可能方向 + 各自含义”供用户选择，**严禁**把查到的资料长篇输出给用户。

### 4.2 选项式澄清与收敛

- **选项优于开放提问**：给 2~4 个理解方向让用户勾选，降低用户表达负担。
- **澄清维度清单**：术语消歧、调研目的（决策 / 学习 / 写作素材）、范围边界（时间、地域、语言）。
- **收敛规则**：追问最多 2~3 轮；仍未确认则带着最优假设继续，并在报告中**显式声明所做假设**，防止无限追问死循环。

### 4.3 调研强度分档

- 三档：`low` / `high` / `max`，关键不是档位数量，而是**差异维度清晰**（示例，待定）：

| 维度               | low      | high     | max                      |
| ------------------ | -------- | -------- | ------------------------ |
| 搜索轮数           | 少       | 中       | 多                       |
| 来源数量与交叉验证 | 基础     | 多源     | 多源 + 矛盾核查          |
| 报告篇幅           | 一页速览 | 标准报告 | 完整报告 + 附录          |
| 交互节奏           | 一次交付 | 一次交付 | 分阶段汇报，可纠偏可中断 |

- **推荐而非询问**：根据主题复杂度、术语歧义度、时效敏感性给出推荐档位 + 一句话理由，用户可改——一次交互完成，不反复追问。
- **默认机制**：用户不回应时直接采用推荐档，避免交互卡住。

## 5. 调研执行要点

- **多语言检索**：中文主题通常需要中英双语交叉验证。
- **来源分层**：官方 / 权威媒体 / 社区观点分开标注，报告中区分“事实”与“观点”。
- **矛盾显式化**：不同来源说法冲突时列出来，不悄悄替用户取舍。
- **时效标记**：区分常青知识与近期变化。
- **max 档分阶段**：先给报告大纲让用户确认再展开，中途可纠偏。
- **增量登记**：每查到一个可用来源，立即写入素材登记簿（见 §6.2），而非调研结束后补写。

## 6. 双产出物

### 6.1 调研报告（面向阅读）

- **基本结构**：摘要 → 主要发现 → 来源引用 → 局限与未覆盖。
- **引用可溯源**：每条关键结论带链接 + 访问日期，并与登记簿条目对应。
- **篇幅随档位变化**：low 是一页速览，max 是完整报告。
- **诚实性章节**：内置“未覆盖与不确定”部分——这本身就是差异化卖点。

### 6.2 素材登记簿（中间文档，面向追溯与复用）

- **定位**：报告的**证据层**——报告是结论，登记簿是原料；两者一起交付。
- **每条记录**：链接、标题、摘要（用户原始要求），外加建议补充的字段：
  - 来源类型（官方 / 权威媒体 / 社区观点）
  - 访问日期、语言、时效标记
  - **支撑了报告中的哪些结论**（反向索引，用户可从任一结论跳回原始证据）
- **排除也留痕**：质量差或被矛盾推翻的来源不删除，标记“已排除 + 原因”——被淘汰的过程本身就是可信度的一部分。
- **生命周期**：随调研过程增量写入，天然形成可审计的调研轨迹。
- **用户视角的价值**：可自行点开原文深读、核验 AI 摘要是否忠实。

## 7. 报告之后的延续交互

- 支持基于报告的**追问**和**“深挖某一节”**——以素材登记簿为知识底座作答，不重新搜索。
- 用户质疑某个结论时，沿登记簿的反向索引**针对性复查**该结论的证据链，而非全量重跑。

## 8. 边界与异常处理

- 搜不到资料、来源质量差、需要付费数据库 / 实时行情 / 一手访谈的场景——**诚实告知局限**，不硬编内容。
- 涉及医疗、法律等敏感领域时，报告定位为信息整理而非决策建议。

## 9. 开放问题

1. **档位差异维度的具体定义**：§4.3 表格为占位示例，需确定各档在轮数、来源数、篇幅上的实际取值。
2. **登记簿字段集合**（新增）：核心三件套（链接 / 标题 / 摘要）已定，附加字段（反向索引、排除标记等）按需取舍。
