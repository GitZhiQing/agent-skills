# deep-research 环境探测细则

按需加载：阶段 0 环境探测时读取本文件。探测全部只读——不发起搜索/抓取、不安装、不建目录、不提问。

## 1. 模型 ID 标准化

- 从系统提示 / 环境上下文尽力识别当前 LLM 的**标准模型 ID**，去掉供应商前缀：`anthropic/claude-opus-4-6` → `claude-opus-4-6`，`openai/gpt-5.2` → `gpt-5.2`，`deepseek/deepseek-chat` → `deepseek-chat`。
- 别名仅在确有把握时映射到规范 slug；无把握保留原样。**不可靠识别标"未知"，不从模型行为猜测身份。**
- 用户纠正值逐字优先于自识别值，写入附录 B「模型」字段。

## 2. 平台启发式信号（开放集合）

平台是开放集合，示例非白名单：Codex / Claude Code / ZCode / DeepSeek Harness / Qoder / Cursor / Gemini CLI / OpenCode 等。综合以下信号判断，不确定标"未知"：

| 信号 | 示例 |
| --- | --- |
| 系统提示自称 | "You are Claude Code" / "You are Codex" / "You are Qoder" |
| 环境变量标记（只读） | `CLAUDECODE`、`CODEX_*`、`QODER_*`、`CURSOR_*`、`GEMINI_*` |
| 工具命名风格 | `WebSearch`/`WebFetch`/`AskUserQuestion` vs `web_search`/`web_fetch` vs MCP 前缀 |
| skill 安装路径 | `~/.claude/skills` / `~/.codex/skills` / `~/.qoder` |

用户纠正值优先，写入附录 B「平台」字段。平台决定子代理 / 任务清单 / 提问工具能力，不硬编码具体工具名作为要求。

## 3. web 工具优先级梯与调用纪律

候选优先级（各选一个，可同一工具兼任搜索与抓取）：

1. **宿主原生** WebSearch / WebFetch 类工具（首选）；
2. **已安装的 web 搜索 / 抓取 skill**（可选协作，"如已安装"；仅提名，不引用其内部路径）——付费 API（如 DeepSeek Search/Fetch）须注明成本；
3. **其他 MCP 搜索工具**。

无论选用哪种通道，都执行本 skill 自身的调用纪律：连续两次搜索/抓取间隔 ≥2 秒；遇限流、连续空结果或超时先退避并重试一次，仍失败如实说明；同一 URL 不重复抓取，优先复用已获取内容。

## 4. 提问工具检测与文本编号降级

- 探测宿主结构化提问 / 选择工具（如 AskUserQuestion、request_user_input、elicitation，**以实际可用为准，不伪造工具调用**）。
- 可用 → 两屏与例外回询优先用工具；**工具只承载短选项，完整事实与计划用文本呈现**。
- 不可用 → 全程文本编号选项，用户回复编号即可：

  ```
  我理解你可能在问（回复编号或直接补充）：
  A. <方向一> —— <一句话含义>
  B. <方向二> —— <一句话含义>
  C. <方向三> —— <一句话含义>
  ```

## 5. git 探测

阶段 0 无条件只读探测 `git --version`（廉价）；仅当用户问题可能涉及源码时在第 1 屏显示 git 可用性。源码调研的获取与固定见 `execution-discipline.md` §3。

## 6. 工作区形态与目录候选

只读检查已有 `research/`、`docs/`、`notes/`、`knowledge/`、代码仓标志与候选父目录可写性（`test -w`，不建目录），生成 2~3 个输出根目录候选与推荐，并入第 2 屏：

- 已有 `research/` → 沿用；
- 代码仓无 `research/` → 优先仓外；
- 文档 / 笔记仓 → 优先仓内 `research/` 或 `docs/research/`；
- 无法判断 → 默认工作区 `research/`。

选项是输出根目录 `<OUT>`，叶目录仍为 `<YYMMDD>-<主题>`。候选不可写或选中路径无法创建时如实报告并请用户改选，不静默落到其他目录。

## 7. 边界

- **零能力**：无任何可用 web 工具 → 如实说明"当前环境无联网搜索能力，无法调研"并终止；禁止用模型内部知识冒充调研结果。
- **无 web 有 git**：可降级为"本地源码调研"——仍执行获取、固定与本地分析，但须在第 1 屏与报告中声明"未做外部资料交叉验证"；web 与 git 均不可用才终止。
- **自主宿主**：宿主声明自主执行 / 用户不在场时，先验证结构化提问工具；不可用、取消或无响应 → 停止并说明"当前会话不满足人类确认前置条件"，不检索、不建目录。
