# video-insight

把一条视频变成可信、可回溯的结构化洞察：先把口播转成文字，做内容结构与话术分析（L1）；需要时再叠加画面帧证据，回答"画面有没有接住口播、字幕排版有没有硬伤、标注时机对不对"（L2）。

## 何时触发

- 用户要求分析一条视频的内容、结构、话术，或提出「拉片」「画面分析」「音画对齐」「节奏分析」「字幕排版检查」；
- 只要意图是理解或评估一条已有视频即适用——未说"分析"二字同样触发；
- 仅需转写或摘要、或要求生成素材 / 剪辑时不适用（见边界）。

## 工作方式

两档，成本差约 3–8 倍；**档位未明确时必须先向用户确认**（流程见 SKILL.md §0；无用户可问时取 L1 并在报告头部显式声明"档位未确认"）：

| 档位 | 做什么 | 实测成本 |
| --- | --- | --- |
| L1 文案档 | 转写 → 校对 → 语义分段 → 口播数据 → 逻辑骨架 → 主张与合规核查 | 约 6–10 分钟、40–130 万 token |
| L2 画面档 | 追加抽帧拼版、帧差量化、定帧回查、局部放大、音频三层检测、区域取色，产出分级问题清单与优化动作清单 | 约 30–40 分钟、330–480 万 token |

执行链：`doctor` 自检 → `fetch`（B站链接）→ `transcribe` → `probe` → L1 分析 →（L2 证据采集）→ 报告 + 证据索引。每个脚本把运行状态与产物清单写进 `manifest.json`，归档失败会在校验中直接暴露。

## 边界

- 不做：转写本身（复用上游 `video-to-subtitle-summary`）、非 B站 链接的视频下载、素材生成、剪辑；
- 链接支持矩阵以实测为准：B站 支持；抖音 / 小红书 / 快手 / 视频号 不支持，`fetch.py` 会拒绝并给出手动下载指引。

## 安装

随仓库任一方式安装（skills CLI / Claude Code 插件市场 / 手动链接），见[仓库 README](../../README.md#安装)。

运行时依赖：

- Python 3.9+，`ffmpeg` / `ffprobe` 在 PATH 中可用；
- B站链接下载需要 `yt-dlp`（或 `uvx`）；
- 转写复用上游 skill `video-to-subtitle-summary` 的 `scripts/transcribe_volcengine_bigmodel.py` 与火山引擎豆包 API Key——把它安装到本 skill 同级目录即自动发现，或用 `VIDEO_INSIGHT_ASR_SCRIPT` 指定脚本路径，或把该脚本复制进本 skill 的 `scripts/`；
- 环境自检：`python scripts/doctor.py --workdir <工作目录>` 一次列出缺失项与补救指引。
