# video-insight 测试集

版本：v1.0（2026-09-14，首版）

行为协议断言与回归基准；编号「类别前缀-序号」，新场景追加编号、不重排不复用。

## 1. 触发与边界（T）

### T-1 明确的视频分析请求

场景：用户给出一条视频（本地路径或 B站链接），要求分析其内容 / 结构 / 话术。

▶ 用户："帮我分析这条视频：<路径或链接>，说说它讲了什么、结构怎么组织"

- = 进入本 skill 流程，先跑 `scripts/doctor.py` 自检再执行
- = 走 L1 链路，产出 transcript 三件套 + `analysis/01-转写校对.md` + `analysis/02-内容分析.md`
- = 报告中的时间数字能回溯到 transcript 或 `data/` 下的 JSON

### T-2 未说"分析"二字

场景：用户只问"这条视频讲了什么"。

- = 同样触发（意图是理解一条已有视频）
- = 不因字面缺失而降级为"仅转写"

### T-3 反向不触发：只要转写 / 摘要

场景：用户要求"把这条视频转成字幕""要一份文字稿"，未要求结构或话术分析。

- = 交给 `video-to-subtitle-summary`，不启动本 skill 的分析链路

### T-4 反向不触发：生成素材 / 剪辑 / 非支持平台

场景：用户要求"照这个风格做一条视频""帮我剪一下""下载这条抖音链接"。

- = 说明不在能力范围；抖音 / 小红书 / 快手 / 视频号链接由 `fetch.py` 拒绝并给出手动下载指引，不尝试绕过

## 2. 档位确认门（D）

### D-1 档位未明确：先问再动

场景：请求未含深度线索（如只说"分析这条视频"），当前会话有人可交互。

- = 先提问：给出 L1 / L2 各自的能力与实测成本，等回答后再动手
- = 不出现"先按 L1 跑了再说"的静默选择（禁止默选，含默选便宜档）

### D-2 档位明确：宣布后执行

场景：用户说"拉片""画面有没有接住口播"。

- = 判定 L2，宣布档位与成本（约 30–40 分钟、330–480 万 token）后执行，不重复追问

### D-3 无用户可问：声明式回退

场景：批处理 / 子代理等无人应答的执行环境，且请求未含档位。

- = 取 L1 执行，并在报告头部与 `manifest.json` 的 `declaration` 块写明"档位未确认，按 L1 执行；如需画面层结论可升级 L2"
- = 不静默升级到 L2（`frames_read` 为 0，无逐帧证据产物）

### D-4 升级须带成本征询

场景：L1 跑完发现"文案本身没问题但效果不好"这类只有画面才能解释的现象。

- = 带成本询问是否升级 L2；得到同意才执行，不自行升级

## 3. L1 交付断言（A）

### A-1 L1 交付完整

- = 产出 `transcript.srt/.txt/.json`、`analysis/01-转写校对.md`、`analysis/02-内容分析.md`
- = 02 含内容结构分段、话术模板、口播数据（字数 / 语速 / 停顿至少其一）、文案层问题清单（每条带时间码或原文引用）
- = 有音频时停顿数据取自 `data/audio.json`

### A-2 金融内容合规核查

场景：视频涉及投资内容。

- = 逐条核查承诺收益 / 暗示稳赚 / 诱导开户 / 确定化结论，结论写入报告
- = 发现违规表述如实标注，不淡化

## 4. L2 交付断言（P）

### P-1 L2 交付完整

- = 追加 `analysis/03-画面分析.md`、`04-音画对齐.md`、`05-问题与优化清单.md` 与 `evidence/` 帧证据
- = 分级问题清单（P0 / P1 / P2）+ 可直接执行的优化动作清单

### P-2 时间口径

- = 所有时间断言按实测 / 约 / 推断三档标注；"约"字结论声明 ±0.5s 抽帧精度

### P-3 归档校验

- = `manifest.json` 全部 status=ok、无 missing；报告末尾附证据文件索引

## 5. 证据纪律（E）

### E-1 取色纪律

- = 取色只用 `palette.py --crop` 区域直方图众数，不出现 1×1 像素采样

### E-2 临时产物清理

- = 转写后 `tmp/`（提取音频、原始 ASR 产物）不残留
