# find-my-xp 角色档案库 · 虚拟歌手 / Vtuber 卷

按需加载：阶段 9 写具体描写 / 匹配用户建构时，与 `corpus-sourcing.md` 配合读取。

**版权与用法**：分析性索引；短引用（适当引用）+ 署名 + 指针 + 分析标签，不整篇搬运。来源层级：官方设定/萌娘百科 > 论坛深析（PTT/知乎/NGA/豆瓣）> 媒体/社区分析（新华网/极客公园/bilibili）。官方设定/萌百/社区讨论为人类创作来源，分析为模型所写。

**本卷两类关键 XP 机制**：
1. **空白容器 / 共创**（虚拟歌姬）：官方设定极简（年龄/发色/代表色），人格由创作者与粉丝填充——用户爱上的可能是"自己投射进去的想象"，而非固定人格。
2. **官方人设 vs 中之人真实**（Vtuber）：吸引力常在 rp 人设与中之人真实性格的反差、以及"藏不住的真实"（口癖/铸币/才女），而非完美皮套。
